# 车厢坐标系与纸箱位姿

- 状态：现行
- 最后确认：2026-07-29
- 阅读对象：产品、业务、机器人对接、开发、测试
- 产品可读：是

本文档是机器人坐标、纸箱尺寸和 `XYZABC` 输出的现行业务事实来源。涉及坐标弹窗、CSV、2D/3D 坐标标记或机器人对接时，必须先阅读本文档。

## 观察视角与原点

观察者站在柜门处，目视车厢内部的角件端。

- 坐标原点 `O` 位于角件端内壁的左下角。
- “左下角”以观察者从柜门望向角件端时看到的方向为准。
- 坐标轴箭头的交点就是坐标原点，不能把示意图中的其他角点当作原点。

## 车厢坐标轴

- `X`：沿车厢长度的反方向。角件端为 `X = 0`，从角件端向柜门推进时，`X` 变为绝对值越来越大的负数。
- `Y`：沿车厢宽度的反方向。从原点横跨车厢内部时，使用非正坐标。
- `Z`：沿车厢高度的同方向。地面为 `Z = 0`，向上为正数。
- 位置单位统一为 `mm`。

简化示意：

```text
观察者 / 柜门
      |
      | 纸箱从角件端向柜门排列时，X：0 -> -1 -> -2 -> ...
      v
角件端内壁（从柜门望去）
┌────────────────┐
│                │
│ O──────────────│  横跨内部时 Y 使用非正坐标
└────────────────┘
  ↑
  Z 向上为正
```

## 内部算法坐标到机器人坐标

算法内部 `BoxPosition` 仍使用适合装柜计算的正向坐标：

- `box.x`：柜长方向，从角件端向柜门递增。
- `box.y`：柜宽方向。
- `box.z`：柜高方向，从地面向上递增。

坐标表输出的不是纸箱中心点，而是纸箱“远离柜门面的左下角”。当前换算为：

```text
X = -box.x
Y = box.y + box.dy - container.width
Z = box.z
```

其中 `box.dx / box.dy / box.dz` 是纸箱当前朝向在车厢内部轴上的占用尺寸。

## 纸箱自身坐标

无论纸箱如何摆放，纸箱自身尺寸定义保持不变：

- 长：纸箱局部 `X` 轴。
- 宽：纸箱局部 `Y` 轴。
- 高：纸箱局部 `Z` 轴。

坐标表中的“长、宽、高”始终输出纸箱原始尺寸，不输出旋转后在车厢三个方向上的占用尺寸。

## 姿态 ABC

`A/B/C` 是纸箱相对于车厢坐标系的欧拉角：

- `A`：绕车厢 `Z` 轴旋转，表示偏航角。
- `B`：绕车厢 `Y` 轴旋转，表示俯仰角。
- `C`：绕车厢 `X` 轴旋转，表示滚转角。
- 欧拉角顺序：`Z-Y-X`。
- 单位：度（`°`）。

旋转矩阵约定为：

```text
R = Rz(A) × Ry(B) × Rx(C)
```

奇异姿态使用确定性的规范化输出，避免同一纸箱朝向在不同运行中得到不同但等价的角度组合。

## 六种纸箱朝向

当前支持的朝向及规范化角度如下：

| 朝向 ID               | 展示     |   A |   B |   C |
| --------------------- | -------- | --: | --: | --: |
| `length-width-height` | 长×宽×高 | 180 |   0 |   0 |
| `width-length-height` | 宽×长×高 |  90 |   0 |   0 |
| `length-height-width` | 长×高×宽 | 180 |   0 |  90 |
| `height-length-width` | 高×长×宽 |  90 |   0 | -90 |
| `width-height-length` | 宽×高×长 | -90 | -90 |   0 |
| `height-width-length` | 高×宽×长 |   0 | -90 |   0 |

如果新增纸箱朝向，必须同时更新本表、`src/core/packing/orientations.ts` 和 `tests/box-coordinates.test.ts`。

## 坐标输出字段

每个纸箱输出：

```text
总ID、SKU、长、宽、高、X、Y、Z、A、B、C、所属层、所属排、排内ID、朝向
```

示例：

```text
总ID：100
长/宽/高：488/380/291
XYZABC：(...)
所属层：1
所属排：6
排内ID：3
```

编号规则见 [`../packing-terminology.md`](../packing-terminology.md)。

## 实现与验收

- 换算与 CSV：`src/core/boxCoordinates.ts`
- 坐标弹窗：`src/components/results/CoordinateDialog.vue`
- 单元测试：`tests/box-coordinates.test.ts`
- 浏览器回归：`tests/packing-e2e.spec.ts`

至少验证：

1. 角件端纸箱从 `X = 0` 开始，向柜门推进时出现更大的负数。
2. 输出锚点不是纸箱中心点。
3. 原始长宽高不会随朝向互换。
4. 六种朝向的 `ABC` 与上表一致。
5. CSV 和界面字段、单位、排序一致。
